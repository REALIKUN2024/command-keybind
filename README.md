# Command Keybind (指令快捷键) - Fabric 26.1

A client-side Fabric mod that lets you bind keys to quickly execute pre-configured commands.

## Features

- Press a key to execute one or more pre-configured commands instantly.
- Fully configurable in-game config screen (add / remove bindings and commands).
- Config stored at `config/command-keybind.json`.
- "Open config menu" key registered into vanilla Controls under its own category (default: `K`).
- ModMenu integration (config button in the mod list).

## Build

```bash
gradlew build
```

Output: `build/libs/command-keybind-<version>.jar`
