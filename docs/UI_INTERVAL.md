# UI 设计：命令执行间隔配置项

> 本文件针对"每条命令执行间隔（tick，默认 0）"配置项的 UI 设计，待用户确认。
> 所有元素仅使用 Minecraft 原版控件。

## 功能语义（已确认）
- 单位 tick，默认 0。
- 0：按下按键后，同 tick 内连续执行该绑定下的全部命令。
- N>0：首条立即执行，之后每条间隔 N tick。

## 方案 A：主界面列表行内新增一列输入框

在主配置界面（ConfigScreen）每行追加一个"间隔"输入框，与指令编辑分开。

```
┌──────────────────────────────────────────────────────┐
│            指令快捷键 配置                      │
├──────────────────────────────────────────────────────┤
│ [创造模式] [改键:G] [间隔: 0 ] [编辑] [×]            │  ← 行 = 名称 + 改键 + 间隔 EditBox + 编辑 + 删除
│ [传送回家] [改键:H] [间隔:20 ] [编辑] [×]            │
│         [＋ 添加绑定]              [完成]            │
└──────────────────────────────────────────────────────┘
```

- 间隔用窄版 `EditBox`（约 50px 宽），输入即写入，非法回退 0。
- 优点：一眼看到所有绑定的间隔，无需进入子页。
- 缺点：主界面行内元素变多，狭窄；EditBox 与列表滚动共存。

## 方案 B：编辑指令子页面顶部加一行（推荐）

保持主界面不变，在**编辑指令子页面**顶部新增一行"间隔"输入框，紧挨名称框。

```
┌────────────────────────────────────────────┐
│        编辑指令 - 创造模式                    │  ← 标题
│   [绑定名称: 创造模式        ]              │  ← 名称 EditBox（已有）
│   [命令间隔(tick): 0        ]              │  ← 新增间隔 EditBox（数字输入）
├────────────────────────────────────────────┤
│ [ /gamemode creative            ] [×]     │
│ [ /say 已进入创造模式            ] [×]     │
│        [＋ 添加指令]      [完成]          │
└────────────────────────────────────────────┘
```

- 间隔 EditBox 放置于 header 垂直 LinearLayout，与名称框同宽（200px）。
- 输入即写入 `BindingEntry.intervalTicks`，非法/负数回退 0。
- 优点：与"这条绑定的命令"放在一起，语义清晰；主界面不拥挤。

## 需要你确认的点
1. 选方案 A 还是 B？（推荐 B）
2. 方案 A/B 中间隔输入框宽度与提示文案：
   - 方案 A：提示 `间隔`（占位）
   - 方案 B：hint `指令间隔(tick)`（占位），输入框宽度 200
3. 是否需要限制只能输入数字？（默认：仅靠解析回退 0，不做字符过滤）
